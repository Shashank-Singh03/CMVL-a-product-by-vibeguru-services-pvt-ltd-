# Finding your way through a change

Start at the dashboard's **All tasks** page. Select a task to see its available map, lessons, analysis and outputs.
The logo and **Home** breadcrumb return to the task library. **Back** returns through the pages and lessons you
visited; browser Back and Forward work too. A page opened directly has a safe Home fallback rather than sending
you to an unrelated site.

The desktop starts with a compact icon rail; each icon keeps its label as a tooltip.
The menu icon at the top opens the labels. Click outside navigation, select a view,
or move keyboard focus out to dismiss it. Escape dismisses and restores focus to
the opening control. On small screens, **Menu** opens the same navigation as a
drawer. Appearance is available there too. The footer credits Shashank.

Maps now open in the dashboard's **Explore map** view. The workspace navigation
stays visible around the map. Map selections update the parent URL and survive a
return from another view. Home, Learning, and Analysis inside the map return to the
corresponding workspace view. A standalone generated map still opens directly when
its file is used outside the dashboard. Recorded videos play within the workspace.

The overview's **Change snapshot** shows one metric at a time. Use its topic buttons
or **Pause rotation** to hold a topic; keyboard focus pauses it too. Reduced-motion
preferences start it paused. Counts describe saved captures, including partial or
unavailable data, and do not measure overall project completion.

Page, task, lesson and selected-change routes are recorded in the URL. You can bookmark a lesson or return to it
after opening its map. A task's **Analyze this task** action scopes the charts to that capture; the Analysis scope
selector also offers **All captured tasks**. Counts retain their existing meaning: captured-file and generation
counts are not accuracy or project-completion scores.

## Read one thing at a time

Learning shows the current step and one selected change example. Use **Previous change**, **Next change** or the
change selector to inspect another excerpt. **See this item in the map** opens that recorded node in its map view.
Only a few relevant terms appear initially; expand more terms or **Browse all definitions** when needed.
On a phone, **Choose a lesson** replaces the full lesson sidebar to leave more room
for reading. Its selection updates the same bookmarkable lesson URL.

Connections link to their selected change example when available, or to the mapped item. A relationship without
a safe recorded target remains plain text. These links are navigational evidence, not claims that a call ran.

## Explore the map

Map pages have **Back**, **Map overview**, and a **Home** link when a real parent dashboard or example overview is
available. Captured task maps also link to the same task's Learning and Analysis views. Selecting a mapped item
that belongs to the learning selection opens its corresponding example when you choose **Learn this change**.

The graph is the main view. **Find an item or filter the map** opens search on demand; choosing a result returns
focus to its map. The right panel starts with an overview, while technical details, source changes, relationships
and risk evidence expand separately. Risk badges and coverage summaries stay visible. Parse problems, unmapped
changes and unresolved/rejected review findings can expand coverage automatically.

Clickable map breadcrumbs take you up the hierarchy. **Back** follows previous map selections; **Map overview**
returns directly to the top. The risk list also has **Back to item**. File-based source handoffs and recorded video
playback retain their existing behavior.

Standalone maps without a parent dashboard still provide Map overview and internal Back navigation. The curated
[Notes app example](../examples/demo-output/index.html) includes its own overview page, with entry links to each
area and the recorded video. Its original audio and analysis payload are retained in the refreshed map.

Generated pages embed their current UI template. Update an installed skill and regenerate task history/maps to
receive the navigation changes; already copied HTML does not update itself.
