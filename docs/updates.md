# Updating CMVL and its dashboard

The beta release is **0.3.0-beta.1**. The command remains `codemap`; CMVL is the
product name. Its version comes from `codemap_lib/__init__.py` and is compiled into
the offline dashboard. The CLI, skill metadata, dashboard and release package use
the same version. The dashboard and map footer show the UI generator version.

## Will everybody see the same dashboard?

The same release ships the same HTML/CSS/JavaScript design and features. It does
not ship everybody's project data. Task records, maps, available videos, configured
options, theme, and personal reading progress depend on each local workspace.
Connected controls are available through `codemap serve`; ordinary file and static
server viewing retain the read-only dashboard features.

Generated HTML includes its own dashboard bundle, so it works offline without Node
or a CDN. That also means an old HTML file retains its old UI. It will not change
because somebody else published a release. Recorded MP4s likewise remain recordings
of the version and capture that created them.

## Install a beta

Download the versioned ZIP from
[GitHub Releases](https://github.com/Shashank-Singh03/CMVL-a-product-by-vibeguru-services-pvt-ltd-/releases),
verify it against the release's SHA256SUMS if desired, extract it, and open a terminal
inside its extracted folder. End users do not need npm to use the bundled dashboard.

```bash
python skills/codemap/scripts/codemap.py --version
python install.py --project /path/to/your/project
```

For automatic Claude walkthroughs, explicitly choose the hooks:

```bash
python install.py --agents claude --auto --project /path/to/your/project
python skills/codemap/scripts/codemap.py auto on /path/to/your/project
```

Restart the agent after installing. Windows paths can be quoted, for example
`"C:/work/my-project"`. A user-wide install uses `python install.py` without
`--project`. Installation does not make automatic Claude mode implicit.

## Move to a newer release

1. Download and extract the newer tagged release in its own folder, or use a clean
   Git checkout of that tag. Keep local application changes in a separate branch.
2. Rerun `install.py` with the same project and agent choices. Include `--auto` when
   updating a project that uses automatic Claude hooks, then restart the agent.
3. Finish or cancel active generation before refreshing saved outputs. New tasks
   generated by the updated installation use the new dashboard and map templates.
4. Refresh an existing project's dashboard using the newer release:

```bash
python skills/codemap/scripts/codemap.py task history /path/to/your/project
```

The resulting `.codemap/index.html` uses the newer dashboard bundle. A static server
does not upgrade templates itself; reload the browser after regenerating the file.
The local `serve` command renders history using the version of the CLI that started
it, so restart that server from the updated installation as well.

To refresh an existing task's **map HTML**, use its saved output folder:

```bash
python skills/codemap/scripts/codemap.py render /path/to/your/project --out /path/to/your/project/.codemap/tasks/TASK_ID/output
```

Rendering reuses the saved analysis and labels. It does not re-run the source
application or replace the task's private before/end captures. Its existing recorded
video stays unchanged; rerender the video separately if you want a new recording.
Learning progress follows the recorded learning revision, so changed lesson content
can require a fresh checklist.

## Future versions

Beta tags use `v0.3.0-beta.1`, `v0.3.0-beta.2`, and so on. Every published tag has a
versioned package, checksums and release notes. A dashboard change is an application
release, even if the parsers did not change. Data schema versions are separate: the
history schema remains version 1 in this beta.

The beta has no unattended self-updater. Users choose when to update their installed
skill and regenerate local pages. This keeps offline use predictable and avoids
changing an in-progress coding task underneath its captured sources.
