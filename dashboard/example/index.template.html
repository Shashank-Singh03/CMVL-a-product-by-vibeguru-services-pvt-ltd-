THE CONNECTIONS

A feature extends beyond its function.

Deleting a note touches how requests reach the app and how data is stored. The API contract describes the requests clients can make; the implementation carries them out.

What is an API contract?

A description of the endpoints, inputs, and responses that software clients can expect. Compare it with the implementation when reviewing a change.

Inspect the API contract ↗
THE TRADEOFFS

Read the deployment changes, too.

The recorded example includes a nightly backup. Infrastructure and pipeline changes influence where data goes and which permissions the application has.

What is infrastructure as code?

Configuration files that describe resources such as storage, services, and access rules. A small text change can change the behavior of a live system.
